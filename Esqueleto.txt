📄 docker-compose.dev.yml
   → Orquesta todos los servicios en modo DESARROLLO:
     - db         → PostgreSQL 15 (base de datos)
     - redis      → Redis 7 (broker de Celery)
     - backend    → Django corriendo con runserver (hot reload)
     - celery     → Worker que ejecuta tareas asíncronas
     - celery-beat→ Scheduler de tareas programadas (recordatorios diarios)
     - frontend   → Vite dev server (hot reload)
     - pgadmin    → Interfaz visual para explorar la base de datos
   ℹ Permite que cualquier integrante levante el 100% del entorno con un solo
     comando sin instalar nada localmente más allá de Docker.

📄 docker-compose.yml
   → Orquesta todos los servicios en modo PRODUCCIÓN:
     - Usa Gunicorn en lugar de runserver (más robusto y eficiente)
     - Agrega Nginx como proxy inverso y servidor de archivos estáticos
     - No expone puertos de BD ni Redis al exterior
     - No incluye pgAdmin (no se necesita en producción)
   ℹ Se usa cuando el sistema se despliegue en el servidor real de la empresa.
